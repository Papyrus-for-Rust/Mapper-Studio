# Dependency notices

`texpresso-2.0.2-MIT.txt` preserves the notice for the pure Rust BC3 compression
dependency. Mapper release staging includes this directory alongside the project
license. The source dependency is pinned in the studio manifest and Cargo lockfile.

The native catalog helper pins `unity-rs-core` 0.6.2. Its MIT license and supplied
third-party notices are preserved in the two `unity-rs-core-0.6.2-*` files and
are included by release staging.

`zlib-rs-0.6.8-Zlib.txt` preserves the notice for the Rust backend used
to compress and read saved map render data.

The Settings and Recipe settings icons come from Pictogrammers Material Design
Icons 7.4.47. `pictogrammers-mdi-7.4.47.txt` preserves the upstream notice, and
`Apache-2.0.txt` contains the full icon license.
