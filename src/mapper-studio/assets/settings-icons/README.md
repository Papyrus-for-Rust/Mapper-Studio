# Settings icons

The SVGs come unchanged from [Pictogrammers Material Design Icons 7.4.47](https://github.com/Templarian/MaterialDesign-SVG/tree/v7.4.47/svg).
Mapper embeds only the 48 × 48 alpha masks. They were rendered with
`@resvg/resvg-js` 2.6.2 using fit-to-width 48, then exported as one alpha
byte per pixel in row-major order. Mapper tints the masks at draw time.

Authors from the upstream icon metadata:

- Google — bank-outline, close, earth, export-variant, folder-outline,
  map-marker-outline, refresh, terrain, train-variant, update.
- Austin Andrews — cube-outline, eye-outline, format-list-checks, pine-tree,
  road-variant, speedometer, theme-light-dark.
- Michael Irigoyen — sprout-outline, waves.
