# Changelog

## Unreleased

- Manage autosaved recipes and recent projects on Home. Rename recipe tabs inline and reopen closed recipes from the library.
- Switch between 2D and 3D on a generated map's seed tab. The 3D viewer loads saved terrain on demand.
- Search recipe settings, browse matching prefabs for the blocklist, and find content rules under Scenery & objects.
- Queue or run a batch from the Generate dropdown. Auto terrain memory defaults to an adjustable 80% system RAM target.
- Windows Setup can update, reinstall, or remove an existing copy. It can also offer a newer installer from GitHub when one is available.

## 0.1.0-beta.4

- Added a Windows installer with the Papyrus logo and a Start menu shortcut.
- Made Uncapped the default for concurrent maps, within CPU and terrain memory limits.
- Added a save prompt before Mapper restarts to finish an update.

## 0.1.0-beta.1

First public Windows beta.

- Generate maps from reusable recipes with independent seeds and batch jobs.
- Follow generation in map tabs and reorder waiting jobs in Queue.
- Adjust monument placement and edit road, trail, and rail splines before applying changes.
- Export playable maps and PNG previews, build terrain with Nodes, and run local recipe plugins.
